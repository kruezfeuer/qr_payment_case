# Сервис оплаты по QR-коду

> Портфолио-кейс системного аналитика по проектированию сервиса оплаты по QR-коду в мобильном банковском приложении.

## О проекте

Данный репозиторий содержит набор артефактов системного аналитика, подготовленных в рамках проектирования нового банковского сервиса.

Цель кейса — продемонстрировать полный цикл работы аналитика:
- анализ задачи;
- определение границ системы;
- описание бизнес-процессов;
- формирование требований;
- проектирование взаимодействий систем;
- описание данных;
- подготовка критериев приемки.

---

# Бизнес-цель

Разработать сервис оплаты по QR-коду внутри мобильного банковского приложения.

Сервис должен позволить клиентам:

- оплачивать покупки с помощью QR-кода;
- получать информацию о платеже до подтверждения;
- видеть результат операции;
- отслеживать историю платежей.

Торговые точки должны получать подтверждение успешной оплаты.

---

# Объем проекта

В рамках MVP реализуются:

- сканирование QR-кода;
- получение данных платежа;
- проверка возможности выполнения платежа;
- подтверждение операции клиентом;
- проведение платежа;
- отображение статуса операции;
- уведомление торговой точки.
