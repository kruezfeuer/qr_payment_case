# Границы системы и допущения


# Область реализации

Сервис отвечает за:

- создание платёжного запроса;
- генерацию QR-кода;
- проверку возможности выполнения платежа;
- создание платёжной операции;
- получение результата обработки;
- передачу статуса участникам процесса.

---

# Входит в систему

| Функция | Описание |
|-|-|
| Создание платежного запроса | Создание операции для конкретной покупки |
| Генерация QR-кода | Формирование QR, связанного с платежным запросом |
| Проверка QR | Проверка существования и актуальности запроса |
| Проведение платежа | Инициирование операции во внешней платёжной инфраструктуре |
| Хранение статуса | Сохранение состояния операции |
| Передача результата | Уведомление торговой точки и клиента |

---

# Не входит в систему

- управление заказами торговой точки;
- расчёт стоимости покупки;
- выпуск банковских карт;
- обработка возвратов;
- бухгалтерские операции.

---

# Внешние системы

| Система | Назначение |
|-|-|
| Система торговой точки | Создание платежного запроса и получение результата |
| Банковское приложение клиента | Сканирование QR и подтверждение оплаты |
| Внешняя платёжная инфраструктура | Проведение операции |

---

# Допущения

- QR-код создаётся для конкретной покупки.
- Один QR-код соответствует одному платёжному запросу.
- Сумма операции определяется торговой точкой.
- Клиент подтверждает оплату самостоятельно.
- Внешняя платёжная инфраструктура является источником итогового результата операции.
- Повторная отправка запроса не должна создавать дублирующий платеж.

---

# Ограничения

- Требуется подключение к интернету.
- Клиент должен быть авторизован в банковском приложении.
- Торговая точка должна быть зарегистрирована в системе.
- Все операции выполняются в режиме онлайн.
