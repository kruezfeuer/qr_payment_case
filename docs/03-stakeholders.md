# Участники системы

## Карта участников

| Участник | Роль | Цель |
|-|-|-|
| Клиент | Инициатор оплаты | Оплатить покупку удобным способом |
| Торговая точка | Получатель оплаты | Получить деньги и подтверждение операции |
| Банковское приложение | Клиентский интерфейс | Позволить выполнить оплату |
| Сервис оплаты по QR-коду | Основная система | Обеспечить обработку платежа |
| Платёжная инфраструктура | Исполнитель операции | Провести денежный перевод |
| Служба поддержки | Обработка обращений | Найти информацию по операции |
| Команда безопасности | Контроль рисков | Проверять подозрительные операции |
| Команда разработки | Реализация | Создать и поддерживать сервис |
| Команда тестирования | Контроль качества | Проверить соответствие требованиям |

---

# Описание участников

## Клиент

Потребности:

- простой процесс оплаты;
- понятная информация о покупке;
- получение результата операции;
- отсутствие повторных списаний.

---

## Торговая точка

Потребности:

- быстрое создание платежа;
- получение подтверждения;
- отсутствие необходимости вручную проверять статус.

---

## Банковское приложение

Ответственность:

- сканирование QR;
- отображение информации;
- подтверждение операции клиентом.

---

## Сервис оплаты по QR-коду

Ответственность:

- управление жизненным циклом платежа;
- контроль статусов;
- интеграция с внешними системами.

---

## Платёжная инфраструктура

Ответственность:

- выполнение операции;
- возврат результата обработки.

---

## Команда разработки

Потребности:

- однозначные требования;
- описание интеграций;
- правила обработки ошибок.

---

## Команда тестирования

Потребности:

- пользовательские сценарии;
- критерии приемки;
- ожидаемое поведение системы.
